# Echo-Electrothon5.0

We are Developing a AR app using unity to spawn a 3d model to perform ISL(Indian Sign Language) guestures in order to bridge the communication gap between deaf people and poeple who dont know sign language.

But communication is supposed to be two way, so we are also building an application in flutter in order to recognize ISL from just the camera of your phone via tensorflowlite. We build a custom model using mediapipe-tensorflow in order to recognize hand movement.
